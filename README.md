# NASA-AZAS 공통 협업 문서

NASA-AZAS 조직의 저장소에서 사용하는 기본 기여 가이드와 PR 템플릿입니다.

- [기여 가이드](CONTRIBUTING.md): 브랜치·커밋·PR 제목 규칙과 리뷰 절차
- [PR 템플릿](pull_request_template.md): 변경 목적, 검증 결과, 리뷰 참고 사항

이 저장소는 공개 상태로 유지합니다. GitHub는 조직 내 저장소에 같은 종류의 파일이 없으면
이곳의 기본 파일을 사용합니다. 기본 파일은 각 저장소에 복사되거나 clone에 포함되지 않습니다.
동작과 우선순위는 [GitHub 공식 문서](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)를 참고하세요.

언어별 코드 스타일, 실행 명령, 테스트 방법은 각 저장소의 README 또는 개발 가이드에서 관리합니다.
개별 저장소에 `CONTRIBUTING.md`가 있다면 이곳의 공통 가이드 링크를 함께 적어주세요.
공통 PR 템플릿을 사용하려면 개별 저장소에 별도 PR 템플릿을 두지 않습니다.

이 저장소의 변경은 기본 파일을 사용하는 조직 저장소에 영향을 주므로 범위를 확인하세요.
브랜치 보호, 필수 승인, CI 등 자동 강제 설정은 각 저장소에서 별도로 관리합니다.
